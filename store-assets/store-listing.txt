=== Name ===

Periwinkle Dream Theme


=== Short Description ===

A soft periwinkle Chrome theme with dreamy lavender-blue tones for calm, comfortable browsing.


=== Detailed Description ===

Periwinkle Dream Theme wraps Chrome in four soft pastel tones: periwinkle, soft sky blue, cloud lavender, and dream white. The frame sits in periwinkle, the toolbar and active tab stay in cloud lavender, and the new tab page settles on dream white.

Active tabs are clearly brighter than inactive ones, and a deep periwinkle ink keeps text and icons readable on the pale surfaces.

It is a pure theme. No JavaScript, no scripts, no analytics, no remote code, no permissions, no data collection. The package is just a manifest file plus one icon.

Install it to bring a softer, quieter tone to every new tab.
